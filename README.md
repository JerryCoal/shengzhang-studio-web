# 生长 · 联网网页版（本地数据模式）

此版本保留 Windows 0.4.0 应用，新增可以通过 HTTPS 访问的联网网页版。网页使用本地注册登录、浏览器加密工作区和无持久存储的联网服务。

## 数据保存与使用

- 本地用户、项目、语料、策略、素材、评论、任务状态和 API 密钥保存在当前浏览器的 IndexedDB，使用登录密码派生的 AES-GCM 密钥加密。
- 注册、登录、保存密钥、编辑项目、导入和检索语料、敏感词处理、自动保存、模板制作和导出在浏览器完成。不同浏览器、设备、域名各自保存，不自动同步。
- 勾选自动登录后，浏览器额外保存不可导出的解锁 CryptoKey，允许本浏览器使用者直接点击用户名进入；可随时取消记住。公共设备请勿启用。
- 发起 AI 或平台请求时，当前操作的项目资料和所需凭证通过 HTTPS 临时发送到网站后端。后端只使用请求内存处理，不建立用户/项目数据库、不写文件、不记录请求正文或密钥；处理结束后交还结果供浏览器加密保存。
- 调用 OpenAI 时明确设置 `store: false`。OpenAI、Seedance、抖音分别按其服务条款处理收到的数据；本应用不承诺替第三方关闭全部安全或计费记录。
- 项目备份和素材导出不包含 API 密钥、OAuth 令牌、快捷登录密钥。备份文件本身为明文，请妥善保管。清除浏览器数据会删除工作区；密码无法找回。

## 可以使用的流程

1. 在自己常用的浏览器中注册本地用户，可选择记住该用户。
2. 在“连接与设置”填写自己的 OpenAI API Key；密钥仅在本地加密保存。点击检查连接，不发起付费生成。
3. 建立项目，填写真实产品事实；在“项目语料库”导入 TXT、Markdown、DOCX、文字型 PDF，先查询确认导入内容。
4. 生成策略并检查引用；确认后生成文案与分镜。末尾使用可编辑敏感词库筛选和替换，保留命中记录。
5. 可选择本地模板制作，也可以配置 Seedance 后先生成 GPT Image 2 首尾关键帧，再确认提交 Seedance，继续查询和下载视频。
6. 抖音需要已审核应用、所需接口权限和账号 OAuth 授权。平台注册回调为网站根地址加 `/oauth/douyin/callback`。在每条发布计划中检查文案、成品、账号、时间并启用；平台确认公开后才显示成功。自有作品评论可自动同步，仍支持手动导入。
7. 根据评论生成复盘，选择采用的经验，供下一轮策划使用。

小红书仍提供素材导出、手动发布、作品链接登记和评论导入。当前没有承诺未接入的通用小红书后台自动发布/采集能力。

## 自动任务和中断

网页版需要保持工作区打开、解锁并联网。关闭、退出、浏览器休眠会暂停后续定时投稿和评论轮询；手机后台不保证准时执行。Seedance 已提交的任务由服务商执行，保存了任务编号后可以重新打开网页查询结果。

每个本地用户通过浏览器 Web Locks 限制同时联网执行，并在发出请求前加密保存未确认请求标记。刷新或网络中断导致结果不明时，不自动重复扣费或投稿。请在服务商控制台核对，在设置页明确解除请求锁定；状态不明的发布计划继续暂停。重新使用前按真实账单核对项目预算。

网络请求期间的项目编辑使用三方合并保留。若同一内容发生冲突，新结果另外加密保留，在设置页可导出，不覆盖用户的新编辑。

持续后台运行请用保留的 Windows 应用。若今后要求网页关闭后也能定时执行，需要另行同意服务器保存任务与授权凭证。

## 部署

推荐先用 Render 免费 Web Service，区域 Singapore，Dockerfile 为 `Dockerfile.web`，健康检查 `/api/health`。`render.yaml` 已配置为 `free`，没有数据库、持久磁盘或付费套餐。正式源站使用平台提供的 `RENDER_EXTERNAL_URL`；换自有域名时设置 `WEB_PUBLIC_ORIGIN=https://你的域名`。两者均不可包含路径。

免费服务闲置 15 分钟会休眠，唤醒通常约一分钟；运行配额、内存和带宽按平台规则执行。当前版本逐个处理联网操作，服务繁忙时在调用服务商前返回提示。单次请求上限 32 MB，适合小型 MVP 项目。模型和视频调用费用由用户自己的服务商账户承担。

代码构建：`pnpm run build:web`。启动：`WEB_PUBLIC_ORIGIN=https://网站域名 HOST=0.0.0.0 pnpm run start:web`。仅本机验收可显式设置 `WEB_LOCAL_TEST=1` 并使用 `http://127.0.0.1:端口`。生产不得开启此测试选项。

Windows 继续使用原启动入口与发布包；不要把 Windows 的 `server/windows.mjs` 服务暴露公网，不把 `%LOCALAPPDATA%/ShengzhangStudio` 上传到托管服务。

## 验证边界

已用模拟服务商响应测试多用户加密、快捷登录、备份去密钥、语料引用、敏感词替换、AI 用量记录、首尾帧到 Seedance、抖音 OAuth、网络中断保护、并发编辑保留。Windows 原功能另做回归。

付费模型调用和真实平台投稿仍需用户自己的有效密钥、账户余额与官方权限；不以模拟测试冒充真实付费调用验证。手机媒体编码、系统休眠行为需具体设备验证。

官方依据：[Render 免费服务](https://render.com/docs/free)、[Render Docker 部署](https://render.com/docs/docker)、[Render 部署配置](https://render.com/docs/blueprint-spec)。
